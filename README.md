## Dynamic Snippets & NGO Modules for Odoo
This repository contains dynamic snippets and customizations for Odoo's website modules, specifically designed for NGOs.

Modules Overview
# Dynamic Snippets
Enhance your Odoo website with dynamic, customizable snippets to improve user experience and content presentation.

# NGO Services Module
Install the module and open the website.
Navigate to the "Site" menu at the top, where you’ll find the "Services" option.
This section provides an intuitive way to explore NGO services dynamically.

# NGO Appeals Module
Install the module and open the website.
Navigate to the "Site" menu at the top and select "Appeals" to view its functionality.
This module is designed to effectively showcase and manage appeals.

# NGO Customization Module
Enhances Odoo’s default behavior for better NGO-specific functionality.
Changes include:
    Replacing "Add to Cart" with "Donate Now" for better user engagement.
Introducing a custom pricing option:
    Added a new field in product.template (is_custom).
    If enabled, the product supports custom donation amounts instead of fixed pricing.

# Installation & Usage
Install the desired module(s) from your Odoo Apps.
Open your website and explore the new menu options under "Site".
Customize and configure settings as needed.
